# claude-code/

The optional Claude Code integration: a skill, a slash command, and a
SessionStart hook.

```bash
./install-skills.sh              # macOS / Linux
.\install-skills.ps1             # Windows
```

Full documentation: [../SKILLS.md](../SKILLS.md)

| Path | Installs to |
|---|---|
| `skills/acc-hud/SKILL.md` | `~/.claude/skills/acc-hud/SKILL.md` |
| `commands/acc.md` | `~/.claude/commands/acc.md` |
| `hooks/acc-hud-session-start.sh` | `~/.claude/scripts/` |
| `hooks/acc-hud-session-start.ps1` | `~/.claude/scripts/` (Windows) |
